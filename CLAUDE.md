# Project: ETF landing page for Czech retail investors

Goal: conversion landing page (lead magnet) comparing NYSE-listed ETFs.
Assignment: docs/zadani.md (Task B). Deadline: 2026-10-16.
Success criterion: could we launch ads on this page tomorrow.

## Rules

- Page copy and ads: Czech. Code, comments, commits: English.
- Every number needs a source URL and retrieval date. Never invent data.
  If a number cannot be verified, say so instead of guessing.
- No return promises. Risk disclaimer required (Czech ad/finance norms).
- Mobile-first. Visitor has a few seconds.
- Do not look like default AI output: no purple gradients, no generic
  "unlock the power of..." copy, no fake testimonials or fake counters.
- Small, incremental commits. Plan before code.
- Decisions belong to the author; propose options with trade-offs.
